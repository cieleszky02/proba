# Sketches

Put the user's sketches of the intended "Connection Section" behaviour here
(e.g. `floor-to-floor.png`, `floor-on-wall.png`, `wall-corner.png`).

Read whatever is here before changing any geometry logic in
`ConnectionTools.tab/Details.panel/ConnectionSection.pushbutton/script.py` —
the sketches are the source of truth for what a given contact case should
look like once sectioned.
